<objective>
Prove, behaviorally, that a `VcoCore` is a self-contained voice.

CORE-03 is a claim about what is *absent*: no static, no global, no shared engine. Absence is exactly what a source-text guard proves badly — a grep catches the obvious declaration form and nothing else, and Phase 29 already recorded what happens when a gate is trusted for coverage it does not have. So the claim is tested as a property instead: run two differently-seeded instances interleaved sample by sample, and require each to reproduce its own solo output bit-exactly. Shared state of any shape breaks that.

That test is trivially green on a correct implementation — and, without care, equally green on a broken one. The researcher measured five distinct ways it goes vacuous, and this plan implements all five, the last of which is a deliberately broken core kept permanently in the test file so the check is observed failing something on every single run.

Purpose: make v2.1 polyphony an additive shell change, evidenced rather than asserted.
Output: `runInterleaveCheck()`, `DeliberatelyBrokenSharedStateCore`, and the two CORE-03 cases appended to `tests/test_vco_core.cpp`.
</objective>

Append to the existing anonymous namespace in `tests/test_vco_core.cpp`, then add one case.

**The helper.** Write `runInterleaveCheck()` as a small template over a core type, so the real core and the positive control go through byte-identically the same drive loop. A control that exercises different code than the check proves nothing — that argument is already written into `check_includes.sh [6/7]`'s banner and applies here unchanged.

Give it a callable parameter that seeds a freshly default-constructed core for instance A or instance B, the sample rate, the block length, and the two per-sample input functors. Inside, it must: construct and seed a fresh core for A and run the block solo; do the same for B; then construct and seed two more fresh cores and drive them interleaved, alternating one sample of A with one sample of B; and count, per instance, how many interleaved samples differ from the corresponding solo sample. Compare with a direct float inequality, never an approximate comparator. Return the two mismatch counts plus the number of positions at which the two solo blocks happen to be equal — that third number is what the caller uses to prove the two signals are distinguishable in the first place.

The helper owns timing exactly as the harness does: overwrite `sampleTime` with one over the sample rate and `sampleRate` with the rate, on every sample, unconditionally, for both instances. Comment that this overwrite is load-bearing and must never become conditional on what the caller's functor happened to put there — the same wording `tests/VcoBlockDriver.hpp:49-52` uses.

**The case.** Name it `vco core: two-instance independence under sample-by-sample interleaving (D-17)`.

At each sample rate, drive 1024 samples with the four seeds spelled out per instance: the same drift pair for both, different spread pairs, using the values the researcher measured so the recorded figures apply to this code. Build two genuinely different input functors from `coreBase()`: instance A sweeps `pitchCV` while holding `character` at 1.0; instance B holds a different fixed pitch and sweeps `morph`, also at `character` 1.0. Different inputs are the third measured requirement — a shared phase accumulator is caught either way, but different inputs also catch a shared frequency, a shared telemetry block or a shared `Waveshape`.

Assert, in this order:

1. **Validity check first.** `REQUIRE` that the helper's solo block for instance A is bit-identical to what a `forge::VcoBlockDriver` constructed with the same four seeds produces over the same inputs. This pins the helper to the harness's own drive discipline; a helper that silently stopped injecting timing would otherwise pass everything below it. This mirrors the `nc2_direct` validity-check habit in `check_includes.sh [6/7]`: assert the fixture tests what it claims before asserting the result.
2. **Distinguishability.** `CHECK` that the two solo blocks are equal at fewer than a tenth of their positions. Without this, "interleaved equals solo" would be satisfiable by two identical signals. Measured with this construction: equal at 0 of 1024 samples.
3. **The property itself.** `CHECK` that both mismatch counts are zero. Measured on the real core: A = 0/1024, B = 0/1024.

Comment the two measured traps at the case so they cannot be optimised away by a later reader: `character = 1.0` is required because at `character = 0` a clobbered shared `Waveshape` is 0/1024 detectable — every spread coefficient in the frozen `Waveshape` is gated behind a `character >= 0.001f` test; and the spread seeds must differ, because with identical seeds a hypothetical shared static shaper would produce identical coefficients and be invisible. Note that the positive control appended by Task 2 is what proves the helper can actually detect a defect.

Add this case as invariant 4 in the file banner's numbered list.
